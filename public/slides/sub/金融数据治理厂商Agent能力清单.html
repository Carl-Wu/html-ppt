口径说明 「已接入治理 Agent」＝以大模型为决策内核、多智能体协同执行治理任务（如元数据/标准/质量 Agent、治理大脑、对话即操作）；「未接 Agent」＝以传统平台 + 单点 AI 辅助（智能推荐/自动落标/资产盘点）或基本无 AI 治理能力的厂商。恩核、数语科技属「有 AI 辅助但非 Agent 编排」，最易与 Agent 化方案混淆，已在清单中单独标注。

已接入治理 Agent的厂商

11 家已落地治理 Agent / 多智能体。

亿信华辰 · 睿治 Agent

全链路 AI 原生 + 全栈信创 + 多行业落地，连续 5 年 IDC 第一。 yourselves。

差异化：全模块闭环 + 私有化 + 金融/政务多行业，不与云厂商拼公有云生态。

阿里云 · DataWorks Data Agent

开发/治理/分析/运维 Agent 套件 + Skill 库，IDC Data Agent 2026 领导者第一。

边界：金融私有化/信创部署能力弱，偏公有云。

百分点 / 用友 / 普元 / 三维天地

百分点垂类大模型全链路；用友 16 Agent 源头治理；普元"数字员工"（落地弱）；三维天地盘点智能体。

边界：百分点偏政务央国企；用友/金蝶绑定 ERP；普元智能化规模化待完善。

华为 / 腾讯 / 火山 / 金蝶 / 微软

华为盘古 DataAgent（信创）；腾讯 WeData 语义协同；火山开发运维 Agent；金蝶嵌入式；Purview 合规一体。

边界：华为绑定云底座；腾讯/火山偏互联网；微软跨国合规。
