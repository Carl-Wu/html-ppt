核心理念

OPP（One-Person Project），一人交付全程

OPP 的"One-Person"是一位真实的 PM 工程师。他把专业判断、客户沟通与关键决策握在手里，把咨询与交付的执行工作交给 AI 专家团与既有平台能力。

👤

PM 实体员工

项目唯一责任人：需求、编排、决策、验收，一人贯穿始终。

🖥️

桌面 Agent 指挥台

EsXWork 调度专家团、分发任务、监控进度、汇总产物。

🏛️

双平台能力底座

睿治与监管报送平台提供数据源/标准/质量/血缘/报表等成熟能力。

一人 = 项目经理 + 售前交接 + 实施指挥 + 验收负责

交付产物

最终落到两个平台的资产

所有交付物最终沉淀在睿治与监管报送平台，形成可复用、可审计的金租行业资产。

睿治 · 数据治理产物

治理成果落平台

  • 数据源清单（核心/信贷/财务/数仓/库）
  • 数据标准库（术语/参考/主数据标准）
  • 质量规则库与整改记录
  • 元数据血缘图谱与影响分析
  • 主数据模型与分类分级策略
  • 治理制度文档与质量评估报告

  • 填报口径与勾稽关系定义
  • 源→指标映射文档与补录方案
  • EAST / 1104 标准化报送包
  • 报送校验报告与直连接入配置
  • 操作手册与培训材料

平台能力改造提升

让 PM + Agent 用得更高效

双平台能力已就绪，但要支撑"一人指挥 Agent 交付"，需做以下 AI Native 化提升，把"人点界面"升级为"Agent 可编排"。

API / MCP 化

功能暴露成工具

将建数据源、建标、配质量、血缘、报表生成等封装为标准化 API / MCP，供 Agent 直接调用，无需模拟点击。

NL2Action

自然语言即操作

PM/专家用中文指令即可"加哪些数据源、建哪些标准、配哪些规则"，平台自动执行。

知识沉淀 / RAG

方法论进向量库

治理方法论、行业模板、历史项目、制度解读向量化，新项目秒级复用，降低 PM 经验门槛。

可观测 / 审计

操作留痕可追溯

Agent 每次调用、配置变更全程留痕，满足金融监管对可解释、可追溯的硬性要求。

安全管控

关键动作需审批

报送提交、重大配置、删除类操作强制 PM 人工确认，确保"AI 提效、人控风险"。

PM 工作台

一站式交付驾驶舱

任务看板、进度、异常、待审批聚合于一处，让一名 PM 掌控多项目并行交付。

技能市场 / 插件化

能力可编排复用

平台能力封装为 Skills 供 Agent 市场调用，新项目像搭积木一样组合专家与技能。
